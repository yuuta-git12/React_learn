# React + Create React App

# Create React App
- Node.jsに組み込まれている「npx」プログラムを使い、Reactプロジェクトを作成する方法
- 単一ページのReactアプリケーションを作成する方法として公式サポートされている（**現在は非推奨**）

# プロジェクトの作成
- 以下のコマンドを実行
```
npx creaet-react-app プロジェクト名
```
- TypeScript版のプロジェクトの作成
- 以下のコマンドを実行
```
npx creaet-react-app プロジェクト名 --template typescript
```
