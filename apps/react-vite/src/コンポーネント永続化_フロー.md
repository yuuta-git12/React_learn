# コンポーネント永続化フロー

`App_usePersist.tsx` と `Persist.tsx (UsePersist)` の動作フローを説明します。

## ファイル構成

```
App_usePersist.tsx (UIコンポーネント)
    └── UsePersist.tsx (カスタムフック)
            └── LocalStorage (ブラウザストレージ)
```

---

## 1. 初回レンダリング時のフロー

```mermaid
flowchart TD
    subgraph App_usePersist.tsx
        A[App_usePersist レンダリング開始] --> B[AlertMessage レンダリング]
        B --> C[useState で name, mail, age を初期化]
    end

    subgraph Persist.tsx
        C --> D[UsePersist&lt;Data&gt; 呼び出し]
        D --> E[storageKey = 'hooks:mydata' を生成]
        E --> F[getValue 関数実行]
        F --> G{LocalStorage に<br/>データがある?}
        G -->|Yes| H[JSON.parse してデータ取得]
        G -->|No| I[initVal = null を返す]
        H --> J[useState に初期値をセット]
        I --> J
        J --> K["[savedValue, setValue] を返す"]
    end

    subgraph App_usePersist.tsx
        K --> L["mydata, setMydata として受け取り"]
        L --> M[画面にフォームを表示]
        M --> N[mydata を JSON.stringify で表示]
    end

    style A fill:#e1f5fe
    style D fill:#fff3e0
    style M fill:#e8f5e9
```

## 4. ページリロード時のフロー

## まとめ

| 処理 | App_usePersist.tsx | Persist.tsx | LocalStorage |
|------|-------------------|-------------|--------------|
| 初回表示 | コンポーネント初期化 | getValue()でデータ取得 | 読み込み |
| 入力中 | onChange でstate更新 | - | - |
| 保存時 | setMydata()呼び出し | setValue()でstate+LS更新 | 書き込み |
| リロード時 | 再レンダリング | getValue()でデータ復元 | 読み込み |

### UsePersistの特徴

1. **useState互換**: `[value, setValue]` の形式で使える
2. **自動永続化**: setValueを呼ぶとstateとLocalStorage両方が更新される
3. **自動復元**: コンポーネント初期化時にLocalStorageから自動でデータを読み込む
4. **キー管理**: `hooks:` プレフィックスで他のLocalStorageデータと区別
