# コンポーネント
- 表示するエレメントを部品化したもの
- **Reactエレメントを返す関数**
- 必要に応じて、組み込んで画面表示を設計する
- コンポーネントの動作と表示のことだけを考えればよい、レンダリングはコンポーネントの呼び出し元が実行する
- **コンポーネントのルール**
  - 関数名が大文字で始まる

# index.tsx(main.tsx)
- Reactのルートに組み込まれるTOPページの表示部分

|ファイル名|プロジェクト作成方法|
|---|---|
|index.tsx|Create React App|
|main.tsx|Vite|

# StrictMode
- タグで囲まれた内部をStrict(厳格)モードで扱うもの
  - 厳格なエラーチェックが有効化される
- Create React Appの場合は`React.StrictMode`
- Viteの場合は`StrictMode`

#　他のファイルからインポートできるモジュールと認識させる
- コンポーネントのファイルの最後には以下の記述を入れることで、外部からのインポートができるようになる
```
# default有無の違い
export オブジェクト;
⇩
import {オブジェクト} from xxx;

export default オブジェクト;
⇩
import オブジェクト from xxx;
```

# コンポーネントへスタイルを引数として渡す場合
## 注意点
- スタイル名：ハイフンでつなげたスタイル名は**キャメル記法に直す必要がある**
  - 例：font-size　→　　fontSize
- コンポーネントの関数では属性に用意される値を１つのオブジェクトにまとめたものが引数として渡される。

# コンポーネントの埋め込み
- 他のコンポーネントに別のコンポーネントを埋め込んで表示する
## コンポーネントのコンテンツを利用する
  - コンテンツがHTMLタグで囲われている内容
  - 例
    - 以下の場合「HELLO!」がコンテンツに該当する
```
<p>HELLO!</p>
```
- propsの「children」プロパティで取り出すことができる
## タグを利用したコンテンツの場合はchildrenとmapメソッドを利用する
- コンテンツHTMLタグで囲われている内容
- 例  
```
<コンポーネント>
  <p>HELLO1!</p>
  <p>HELLO2!</p>
</コンポーネント>
```
- 配列としてchildrenに保管される
